# Islamic Companion

A comprehensive ASP.NET Core MVC web application designed to help users build and maintain daily Islamic habits. It tracks daily tasks, adhkar , and fosters a sense of community through a built-in friends system.

---

## 🌟 Features

*   **Habit & Task Tracking:** Complete daily Islamic activities and watch your daily and lifetime task scores grow.
*   **Adhkar Sessions:** Monitor your morning and evening adhkar consistency and track your lifetime session count.
*   **Streak System:** Keep your momentum going by tracking your current and highest daily activity streaks.
*   **Community & Friends:** Connect with friends, view their profiles, and encourage each other by comparing total completed tasks on custom Islamic-themed UI cards.
*   **Detailed History:** Look back at your previously completed tasks with a fully dynamic history log grouped by date.

---

## 💻 Tech Stack

*   **Framework:** ASP.NET Core MVC (C#)
*   **Database:** SQL Server
*   **ORM:** Entity Framework Core
*   **Frontend:** HTML5, CSS3, JavaScript, Razor Views (`.cshtml`)
